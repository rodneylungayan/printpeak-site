# Image slots

Drop real images here with these exact names, then point to them in `src/content/home.ts`.
Run `npm run check:assets` to check sizes and ratios.

| Folder | File | Size / ratio | Format | Used for |
|---|---|---|---|---|
| `logo/` | `logo.svg` | any, square-ish mark + wordmark | SVG | Header and footer (swap in `src/components/Logo.tsx`) |
| `hero/` | `hero.webp` | 1200×1000 (6:5), under 350 KB | WebP | Hero image (`hero.image` in `home.ts`) |
| `projects/` | `pp-01.webp` … `pp-06.webp` | 1200×750 (16:10), under 200 KB each | WebP | Product cards (`image` on each product in `home.ts`) |
| `og-default/` | `og-default.png` | 1200×630, under 900 KB | PNG | Optional fixed share image (one is generated by `app/opengraph-image.tsx` today) |

Until a slot is filled, the site uses drawn art (jersey and product icons), so nothing looks broken.
Always write real alt text that says what is in the photo.
